# Test 2 — Student Records Dashboard

**Time:** 3 hours

> Direct practical task. No questions to answer. Complete the application, test it, commit it on a feature branch, push it, and create a PR to `main`.

## Task

Build a **Student Records Dashboard** using HTML, CSS, JavaScript, and Node.js.

### 1. Frontend — HTML & CSS

Create a dashboard containing:

- Header/navigation
- Student registration form: roll number, name, course, semester, marks, city
- Search by student name
- Course filter
- Student records table
- Summary section showing total students and average marks

Use Flexbox, spacing, borders, hover effects, and responsive styling.

### 2. Frontend — JavaScript

Implement:

- Load student records from the provided JSON data.
- Render records dynamically.
- Search students by name.
- Filter students by course.
- Add a student through the form.
- Validate required fields and marks range.
- Delete a student.
- Calculate and display total students.
- Calculate and display average marks.
- Update the UI immediately after add/delete/search/filter operations.

### 3. Node.js

Using `fs`, JSON, `require()`, and `module.exports`:

- Read the student JSON file.
- Parse it with `JSON.parse()`.
- Create a separate utility module with reusable student-data functions.
- Import the functions into the main Node.js file.
- Add a new student record.
- Save the updated data back to the JSON file.
- Display useful information about the student records in the terminal.

### 4. Git/GitHub

Use a feature branch, make meaningful commits, push the branch, and open a PR to `main` with a short testing summary.
