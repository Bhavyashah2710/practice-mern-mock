# MERN Mock Assessment

This repository is a practice environment for a Git, GitHub and MERN full-stack practical assessment.

## How to Practice

Start by reading **TEST.md**.

Do not look for a solution branch. Treat the repository as an actual test:

1. Clone the repository.
2. Create `feature/<your-name>`.
3. Implement the assessment.
4. Test the application locally.
5. Commit your changes with meaningful messages.
6. Push the feature branch.
7. Open a Pull Request into `main`.

### Assessment

See [`TEST.md`](TEST.md) for the complete requirements, marks distribution and submission checklist.
