# Test 4 — Expense Tracker & Report

**Time:** 3 hours

> Direct practical task. No questions to answer. Complete the application, test it, commit it on a feature branch, push it, and create a PR to `main`.

## Task

Build an **Expense Tracker & Report Dashboard** using HTML, CSS, JavaScript, and Node.js.

### 1. Frontend — HTML & CSS

Create:

- Header/navigation
- Expense form: expense ID, title, amount, category, date
- Search input
- Category filter
- Expense table
- Summary cards for total expenses, number of expenses, and average expense

Use Flexbox, hover effects, spacing, borders, and responsive styling.

### 2. Frontend — JavaScript

Implement:

- Load expenses from JSON.
- Dynamically render expenses.
- Search by title.
- Filter by category.
- Add expense.
- Delete expense.
- Validate amount and required fields.
- Calculate total, count, and average.
- Calculate category-wise totals.
- Display the highest expense.
- Add a sorting option for amount or date.
- Update the UI immediately after every operation.

### 3. Node.js

Use `fs`, JSON, `require()`, and `module.exports`:

- Read and parse the expense JSON file.
- Create a separate utility module.
- Export reusable functions.
- Import and use those functions in the main Node.js file.
- Add and remove expense records.
- Calculate report information in Node.js.
- Save the modified data back to JSON.

### 4. Git/GitHub

Use a feature branch, make meaningful commits, push it, and create a PR to `main`.
